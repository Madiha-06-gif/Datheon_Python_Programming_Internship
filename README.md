
# Hangman Word Guessing Game

## About the Project

This is my first task for the Datheon Python Programming Internship. I created a Hangman game using Python.

In this game, the computer selects a random word, and the player tries to guess it by entering one letter at a time.

## Features

- Random word selection
- Six incorrect attempts
- Displays Hangman drawings
- Tracks guessed letters
- Prevents repeated guesses from reducing attempts
- Displays win or lose messages

## Technologies Used

- Python 3
- Random module

## How to Run

1. Install Python 3.
2. Download this project.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

   python hangman.py

## What I Learned

While making this project, I practised Python loops, if-else conditions, sets, strings, functions, and user input. I also learned how to check guesses and control the flow of a game.
