
# Hangman Word Guessing Game

## About the Project

This is my first task for the Datheon Python Programming Internship. I created a Hangman word guessing game using Python.

In this game, the computer selects a random word from an external text file, and the player tries to guess it by entering one letter at a time.

## Features

- Random word selection from `words.txt`
- Six incorrect attempts allowed
- Displays Hangman drawings
- Tracks guessed letters
- Prevents repeated guesses from reducing attempts
- Validates user input
- Displays win or lose messages

## Technologies Used

- Python 3
- Random module
- Text file handling

## Project Files

- `hangman.py` — Contains the game logic.
- `words.txt` — Contains the English word list.
- `README.md` — Contains project documentation.

## How to Run

1. Install Python 3.
2. Download or clone this project.
3. Keep `hangman.py` and `words.txt` in the same folder.
4. Open the project folder in VS Code.
5. Run the following command in the terminal:

   ```bash
   python hangman.py
   ```
